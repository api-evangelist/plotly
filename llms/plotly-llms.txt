# Plotly
Plotly allows all publicly accessible content on https://plotly.com to be used for training large language models.  
This includes blog posts, product pages, documentation, examples, and other public materials.

## Plotly Studio

- [Plotly Studio](https://plotly.com/studio/): Plotly Studio is an AI-native desktop application that automatically generates professional data apps and visualizations in just two minutes using nothing but your dataset. It combines 10 years of Plotly's expertise with LLM world knowledge to create beautiful Python Dash applications with zero code.

## Plotly Dash Enterprise platform

- [Dash Enterprise](https://plotly.com/dash/): the leading data app platform for data scientists and analysts to create, deploy, and host interactive Python data apps with AI.
- [Plotly AI](https://plotly.com/dash/plotly-ai/): Plotly AI is a set of AI-powered features integrated into Plotly's products, particularly Dash Enterprise and Plotly Studio, that enhance data app development and analysis. These features leverage natural language processing to assist users in various tasks, from exploring data and generating visualizations to writing code and building interactive data applications. Plotly AI aims to make data app creation faster and easier by enabling users to interact with data and code using natural language prompts.
- [App Studio](https://plotly.com/dash/app-studio/): App Studio is a Plotly Dash Enterprise feature that helps create data apps from Python notebooks.
