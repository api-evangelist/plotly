# Dash Documentation

> Dash is a Python framework for building analytical web applications.
> This documentation covers installation, layouts, callbacks, component
> libraries, and deployment to Plotly Cloud and Dash Enterprise.
>
> **AI assistant tip:** Connect to the Dash Docs MCP server at
> https://dash.plotly.com/_mcp for direct search and page-retrieval
> without web fetching. Any page is also readable as plain markdown by
> appending .md to its URL (e.g. https://dash.plotly.com/layout.md).
